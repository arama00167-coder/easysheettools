# EasySheetTools

Free Excel Templates, Calculators & Guides — a fast static website (HTML/CSS/JS, generated by `build_site.py`).

- 20 free Excel templates with guides, formulas explained and FAQs
- 11 online calculators that run in the browser
- 3 Excel tutorials with practice files
- Mascot: Sheetu. Colours: Excel Green #10793F + Navy #163258 + Amber #F4B400

Download files are stored in `/dl/` as base64 text so the whole site stays in Git; the site JavaScript decodes them into real .xlsx downloads in the browser.
