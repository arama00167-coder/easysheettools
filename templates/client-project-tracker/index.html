What's inside this client & project tracker

  • One row per project: client, project, value, dates, status
  • Payment status dropdown: Not Invoiced / Invoiced / Paid / Overdue
  • Overdue rows highlight automatically
  • Total project value and amount still outstanding at the top
  • Notes column for the small details that matter

How to use it — step by step

  1. Add each new project as a row the day you agree it.
  2. Update the status when you send the invoice.
  3. Mark Paid the moment money lands.
  4. Check the tracker every Monday — overdue rows stand out in red.
  5. At month end, compare with your Income Tracker totals.

The formula, explained simply

Outstanding = SUMIF(Status, not "Paid", Project Value)

SUMIF totals only unpaid projects, so the 'money still to come' figure at the top is always live and always honest.

The sample tracker manages 6 projects worth 3,450 in total, with 650 still outstanding and 1 payment flagged overdue — visible in seconds.
