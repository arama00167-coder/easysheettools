How to Use VLOOKUP in Excel

VLOOKUP has been Excel's lookup workhorse for decades. Older files everywhere use it, so every Excel user should understand it. This guide explains it with an employee example and shows you the mistakes that cause wrong answers.

Last updated: October 31, 2026 · Reading time: about 5 minutes · Includes a free practice file

What VLOOKUP does

VLOOKUP searches the first column of a table for a value, then returns a value from a column to its right on the same row. The V stands for Vertical — the table is searched top to bottom.

The VLOOKUP formula

=VLOOKUP(what to find, table, column number, FALSE)

The last part matters most: FALSE means 'exact match only'. Leave it out (or use TRUE) and VLOOKUP may return a wrong, approximate answer without any warning.

Step-by-step example: find an employee's department

ID (A)Name (B)Department (C)
101Ahmad RazaSales
102Sara LeeAccounts
103John SmithSupport
  1. Click where you want the department.
  2. Type =VLOOKUP(102, A2:C4, 3, FALSE)
  3. Press Enter — the answer is Accounts (column 3 of the table, counting from the ID column).

The 3 classic VLOOKUP mistakes

  • Forgetting FALSE — the most dangerous one. The formula 'works' but quietly returns wrong rows on unsorted data.
  • Looking left — VLOOKUP can only return columns to the RIGHT of the lookup column. Move the column, or use XLOOKUP.
  • Column number drift — insert a column into the table and '3' now points somewhere else. XLOOKUP does not have this problem.

The #N/A error, explained

#N/A simply means 'not found'. Before panicking, check: extra spaces in names, numbers stored as text, or a typo in the ID. Wrap the formula in IFERROR to show a friendly message: =IFERROR(VLOOKUP(...), "Not found").

Frequently asked questions

What does the column number mean in VLOOKUP?

It counts columns inside your selected table, starting at 1 for the lookup column itself — not the spreadsheet's column letters.

Should I learn VLOOKUP or XLOOKUP first?

XLOOKUP for new work — it is simpler and safer. Learn VLOOKUP second so you can read and fix the millions of older files that use it.

Why does my VLOOKUP return the wrong row?

Almost always because the 4th argument is missing or TRUE on unsorted data. Set it to FALSE for exact matches.
